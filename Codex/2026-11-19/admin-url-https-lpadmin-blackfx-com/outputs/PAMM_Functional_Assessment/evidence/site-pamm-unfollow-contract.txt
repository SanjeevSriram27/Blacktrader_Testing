API REFERENCE / PAMM
Settle and leave a PAMM pool
POST
/v1/oms/{instance}/pamm/unfollow
Bearer token
Write

Settles the active subscription with this master: master_share = running_pnl x share_percent / 100 when running_pnl > 0, else 0; payout = deposit + running_pnl - master_share (rounded to 2 dp).

The payout comes out of the manager's trading balance (which may go negative) into the follower's, on the instance the subscription was opened on (not necessarily the URL's instance).

Funds events and history rows are written on both sides and the manager gets a pamm_unfollow websocket event.

Behavior & account differences
Choose an available account

Examples use paper. First call GET /oms/_instances and replace the instance with a slug available to your account. Features vary by broker and account type.

Path parameters
instance
string
required

The trading account (instance) slug.

Engine accounts: paper, paper-net, real, real-net.

External venue accounts: binance, zerodha (see the venue notes on each operation).

Only the instances this install is licensed for exist; GET /oms/_instances lists them.

An unknown slug answers 404 no such OMS instance: <slug>.
